Projetos

Website bancário

Desenvolvimento de uma aplicação web bancária interativa no âmbito de uma formação em JavaScript (Udemy, instrutor Jonas Schmedtmann). O projeto consistiu na implementação de toda a lógica em JavaScript, partindo de uma estrutura base em HTML e CSS já definida. A aplicação permite visualizar o extrato bancário com o histórico de transações, consultar o saldo total e analisar métricas como entradas, saídas e juros acumulados. Foram ainda desenvolvidas funcionalidades dinâmicas, como transferências entre contas, pedidos de empréstimo e eliminação de conta, com atualização automática da interface, demonstrando conceitos fundamentais de manipulação do DOM, arrays, eventos e lógica de negócio.

Jogo do dado

Desenvolvimento de um jogo interativo baseado em lançamentos de dados, no âmbito da mesma formação em JavaScript (Udemy, instrutor Jonas Schmedtmann), sendo responsável pela implementação de toda a lógica em JavaScript. O jogo permite a dois jogadores acumularem pontos através de lançamentos sucessivos de um dado, podendo optar por guardar (“hold”) o valor acumulado ou arriscar novas jogadas. Caso seja obtido o valor 1, o jogador perde a pontuação da ronda e a vez passa para o adversário. O objetivo é atingir os 100 pontos em primeiro lugar. Este projeto permitiu consolidar conceitos fundamentais como manipulação do DOM, gestão de estados, controlo de eventos e atualização dinâmica de elementos visuais, incluindo a utilização de imagens.

Jogo de adivnhar o número secreto

Desenvolvimento de um jogo interativo de adivinhação de números no âmbito da formação em JavaScript (Udemy, instrutor Jonas Schmedtmann), com foco na implementação da lógica em JavaScript sobre uma base já definida em HTML e CSS. O objetivo do jogo é descobrir um número secreto dentro de um intervalo definido, no menor número de tentativas possível. A cada tentativa, o sistema fornece feedback dinâmico indicando se o valor introduzido é superior ou inferior ao número pretendido. Este projeto permitiu consolidar conceitos como manipulação do DOM, validação de input, controlo de eventos e lógica condicional, bem como a atualização dinâmica da interface em tempo real.

Interface para empresa de aluguer de veículos

Desenvolvimento de uma aplicação desktop em Python, utilizando a biblioteca Tkinter, com o objetivo de gerir uma empresa de aluguer de veículos. A aplicação integra uma base de dados SQL local para armazenamento e gestão de toda a informação, incluindo utilizadores, veículos, alugueres e dados financeiros. Foi implementado um sistema de autenticação com registo e login de utilizadores, bem como múltiplas funcionalidades, como visualização de veículos disponíveis e alugados, gestão de clientes, análise de receitas e identificação de viaturas que necessitam de revisão ou regularização. O sistema foi desenvolvido de forma integrada, garantindo consistência entre dados — por exemplo, veículos alugados deixam de estar disponíveis e os respetivos valores são automaticamente refletidos nas finanças da empresa. Foram ainda implementados mecanismos de filtragem para facilitar a navegação e pesquisa de informação, consolidando conhecimentos em bases de dados e desenvolvimento de interfaces gráficas.

Jogo do 4 em linha

Desenvolvimento de um jogo de “4 em linha” em C++ durante a universidade, com opção de jogo entre dois jogadores humanos ou contra o computador. A interação é baseada em inputs de texto, onde os jogadores indicam a coluna em que desejam colocar a peça. Foi implementada uma lógica de jogo completa, incluindo verificação de vitória, gestão do tabuleiro e níveis de dificuldade ajustáveis, em que o computador aumenta a sua estratégia para bloquear jogadas do adversário e criar oportunidades de vitória. Este projeto permitiu consolidar competências em programação estruturada, lógica de algoritmos, controlo de fluxo e simulação de inteligência básica.
